# PGS v0.0.2 — Identidade própria consolidada (candidata)

Atualização incremental da linha **PGS — Pokémon GO Spoofers**, baseada no jogo **Pokémon GO 0.439.0** (ARM64). Este release incorpora a limpeza de identidade já auditada na PR #33 ao DEX do aplicativo, sem substituir as bibliotecas do jogo ou o joystick.

## Alterações desta versão

- Textos públicos, notificações e contadores passam a exibir PGS, com 11 idiomas preservados
- Atalhos e links PGS: https://github.com/LucianoToscano/PGS e https://discord.gg/SdwU4VnfW
- Anúncios Discord de release isolados da configuração PGS e exigindo APK completo e checksum
- Branding auxiliar da web, arquivos de backup novos e logs revisados; dados antigos continuam aceitos
- Link de patrocínio Ko-fi antigo removido, sem redirecionamento indevido
- Logo interna original e joystick permanecem intocados

- Nome do instalador Actions: **PGS v0.0.2.apk**
- Asset do GitHub Release: **PGS.v0.0.2.apk**
- Package: `com.nianticlabs.pokemongo`
- Nome instalado: **Pokémon GO**
- Game version: **0.439.0**
- Android `versionCode`: **2026111605**, após **2026111604** na PGS v0.0.1
- Certificado SHA-256 permanente: `D9:5C:6B:DF:CB:D9:1D:C5:C9:CD:E6:98:48:7C:88:E4:99:47:71:A4:75:E4:EF:DE:45:67:B8:D5:F4:4E:96:CF`

A compilação verifica SHA-256 da versão anterior, assinatura, integridade ZIP, identidade do pacote, alinhamento e hashes dos arquivos originais (exceto controles PGS e `versionCode`). Todos os hashes da nova entrega constam de `SHA256SUMS.txt` e `PGS.json`.
