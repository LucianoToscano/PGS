## Verification

The new local verifier checks archive completeness, alignment, the actual certificate and manifest, version continuity, the coordinated Java/ELF/asset layout, and that the experimental browser OAuth path is not enabled or declared. It never signs, installs or publishes anything.

The third-party OAuth prototype has been retired in the proposed source: its identifiers and network exchange are removed, the callback is disabled, and old enable flags cannot restore it. Normal game sign-in is not deliberately replaced by this path; real login is still unverified.

No new signing key or external APK is required for the synthetic tests.
