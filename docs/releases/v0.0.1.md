# PGS v0.0.1 — Identidade própria e atualizações PGS

Primeiro número de versão pública independente do **PGS — Pokémon GO Spoofers**, com base técnica PGRazor v0.3.8 e Pokémon GO **0.439.0** (ARM64).

## Melhorias

- O painel de configurações exibe **PGS** e o número `v0.0.1`. A logo interna do menu e o joystick permanecem como estavam.
- O atalho Discord aponta para a comunidade oficial PGS: https://discord.gg/SdwU4VnfW.
- O atualizador interno deixa de procurar releases do PGRazor e consulta o repositório GitHub PGS, com validação por SHA-256 e comparação de versão própria.
- O arquivo de distribuição passa a ter nome versionado: **PGS v0.0.1.apk**.
- O site, os links de download e as instruções da linha PGS passam a apontar ao projeto PGS.

## Instalação e identidade

- Nome instalado: **Pokémon GO**.
- Android package: `com.nianticlabs.pokemongo`.
- Assinatura permanente: SHA-256 `D9:5C:6B:DF:CB:D9:1D:C5:C9:CD:E6:98:48:7C:88:E4:99:47:71:A4:75:E4:EF:DE:45:67:B8:D5:F4:4E:96:CF`.
- Próximo `versionCode`: maior que `2026111603`; confira o código final no recibo da build assinada.

O PGS de mesmo identificador e assinatura poderá receber a atualização sobre a instalação existente, sem desinstalação. A atualização entre `v0.3.8-pgs.3` e `v0.0.1` deverá ser iniciada manualmente, porque o aplicativo antigo ainda consulta os releases do PGRazor.

**Limite de validação:** a criação de build ou release no GitHub não confirma instalação, login ou uso no celular. Esses testes devem ocorrer antes da publicação como versão funcional.
