# PGS v0.0.2 — Independent branding consolidated (candidate)

[🇺🇸 English](https://github.com/LucianoToscano/PGS/blob/main/docs/releases/v0.0.2.md) · [🇧🇷 Português (Brasil)](https://github.com/LucianoToscano/PGS/blob/main/docs/pt-BR/releases/v0.0.2.md)

This incremental release of **PGS — Pokémon GO Spoofers**, based on **Pokémon GO 0.439.0** (ARM64), brings reviewed independent PGS branding into the APK's control DEX. Game-native libraries and joystick behavior are unchanged.

## Changes

- Public text, notifications, and counters display PGS, preserving all 11 translated in-app catalogs.
- PGS links: https://github.com/LucianoToscano/PGS and https://discord.gg/SdwU4VnfW
- Discord announcements use PGS-only release configuration and require a complete APK and checksum.
- Auxiliary web branding, new backup metadata, and logs reviewed; old saved data remain accepted.
- Former Ko-fi sponsorship link removed without redirecting to an unrelated account.
- Original in-game menu artwork and joystick left untouched.
