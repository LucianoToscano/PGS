# Módulo Root — estado no PGS

**Não há um instalador Root aprovado ou publicado para a linha atual do PGS.**

O APK oficial da candidata `v0.0.2` é o instalador completo **sem root**, disponível no [workflow PGS](https://github.com/LucianoToscano/PGS/actions/workflows/pgs-v0.0.2-release.yml). O nome do aplicativo instalado é **Pokémon GO** e seu identificador continua `com.nianticlabs.pokemongo`.

Existem fontes e testes experimentais para Root no repositório, mas eles **não são** releases de instalação do PGS. Não use instaladores Root de outros projetos para atualizar o PGS: assinaturas, versões, módulos e preferências podem divergir.

Qualquer versão Root do PGS precisará de validação própria de segurança, compilação, certificação, compatibilidade do Android e testes físicos antes de distribuição.

Para a compilação atual e as regras da chave definitiva, consulte [BUILDING.md](BUILDING.md) e [PGS_UPDATE_POLICY.md](PGS_UPDATE_POLICY.md).

O histórico técnico anterior continua disponível no histórico de commits Git do repositório, sem ser anunciado como funcionalidade validada do PGS.
